std::vector< int > Auswahl::getAusgewahlteEinheiten ( )

Get the Ausgewahlte Einheiten object.

Rückgabe
std::vector<int> Gibt die Indexe der Einheiten zurück. Wenn man nach der Starke absteigen sortiert hat erhalt man mit getEinheit()[getAusgewahlteEinheiten()[1]]; die Starkste Einheit aus den Ausgesuchten Einheiten.

◆ leeren()

void Auswahl::leeren ( )

Leert das interne Objekt in dem die herausgesuchten einheiten gespeichert werden.

Achtung
Die Funktion sollte vor jeder suche Aufgerufen werden! Die Einige Ausnahme ist das man nach mehreren Eigenschaften suchen will wie verlete und geringe Truppenmoral.
